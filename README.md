# Sistema Estudiantil - JavaFX

## Descripción

Aplicación desarrollada en JavaFX que permite registrar información estudiantil y realizar cálculos matemáticos mediante una interfaz gráfica amigable.

La aplicación integra los componentes básicos de JavaFX solicitados en la práctica: Label, TextField, ComboBox, ListView y Button.

---

## Funcionalidades

### Encuesta Estudiantil

- Registro de nombre y edad.
- Selección de carrera.
- Selección de semestre.
- Selección múltiple de materias favoritas.
- Visualización del registro realizado.
- Limpieza de campos.

### Calculadora Matemática

- Suma.
- Resta.
- Multiplicación.
- División.
- Potencia.
- Raíz cuadrada.
- Módulo.
- Promedio.

Además, se almacena un historial de operaciones realizadas.

## Ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Actualizar dependencias Maven.
3. Ejecutar la clase:

```java
AplicacionJavaFX
```

4. Utilizar la interfaz para registrar información estudiantil y realizar cálculos matemáticos.
